# Project instructions

## UI and design

- Before creating or substantially changing user-facing UI, load `frontend-design` and `ui-ux-pro-max`.
- Keep the existing Next.js, React, Tailwind CSS, Radix UI, and Lucide stack; do not add a UI dependency unless the task requires it.
- After UI changes, load `web-design-guidelines`, audit the changed interface, and fix applicable findings before delivery.
